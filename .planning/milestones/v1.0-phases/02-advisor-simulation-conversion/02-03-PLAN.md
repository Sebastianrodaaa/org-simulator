<objective>
Thread `track` from CivicBridge `/simulate` UI through Backend validation and into the Simulation service so live WebSocket streaming uses advisor personas end-to-end.
</objective>

<threat_model>
## Threat Model

**Assets:** API contract stability, backward compatibility for manual API clients.

**Threats:**
- **Medium:** Omitting `track` breaks existing clients expecting departments validation.

**Mitigations:**
- Keep `departments` field but relax validator when `track` is provided (optional empty list); retain legacy validation when `track` is absent.

</threat_model>
