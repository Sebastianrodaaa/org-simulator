      After `department_templates()`, add:

      ```python
      def advisor_track_templates(track: str) -> list[str]:
          sec = simulation_section()
          raw = sec.get("advisor_tracks") or {}
          if not isinstance(raw, dict):
              return []
          ids = raw.get(track)
          if not isinstance(ids, list):
              return []
          return [str(x) for x in ids if x]
      ```

      Export remains via normal imports; clear `_cached` is not required for first load.
    </action>
